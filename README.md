# Ejercicio SQL - Ventas de tecnología

Ejercicio práctico de SQL utilizando SQLite y Python en Google Colab.

## Objetivo

Practicar consultas de extracción, filtrado y agregación sobre una tabla de ventas.

## Contenido

El notebook incluye consultas para:

- Seleccionar y ordenar productos por precio.
- Filtrar ventas por país y precio.
- Identificar valores nulos.
- Calcular ingresos totales por categoría.
- Filtrar categorías utilizando `HAVING`.

## Herramientas

- Python
- SQLite
- Google Colab
